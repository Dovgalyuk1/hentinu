# HENTINU BODEN LAPTOP ($HENTINU)

Static one-pager for the $HENTINU meme coin on Robinhood Chain — the shiba who drowned the laptop,
signed the repair ticket with a paw, never came back, and buried the backup somewhere in the garden.

- `index.html` — the whole site (inline CSS/JS, no build step). THE GARDEN: 24 patches of grass,
  8 of them hide a bone with a file on it; digging unlocks the file cards below.
- `assets/` — character cut-outs

Deploy: push to GitHub, import the repo in Vercel. No build command, no framework — static files.
Contract/X links live in the `window.CONTRACT` / `window.TWITTER` block at the top of `index.html`.
